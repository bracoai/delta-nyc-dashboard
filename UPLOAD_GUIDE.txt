WHAT THE NAMES MEAN

app.py and dashboard_model.py are Python program files.
requirements.txt is a file listing the software the cloud service installs.
README.md is a plain-text explanation displayed by GitHub.
.gitignore is a small settings file used by Git. Keep its leading dot.
.streamlit is a folder. Its config.toml file controls the website theme.
assets is a folder containing the logo and its source attribution.
data_v2 is a folder containing the already-prepared data and its build record.
UPLOAD_GUIDE.txt is this guide. You can double-click it to read it in Notepad.

These are file/folder names, not commands. A slash in a path means 'inside':
.streamlit/config.toml means the file config.toml INSIDE the .streamlit folder.
'Commit changes' is GitHub's button for saving uploaded files to the repository.
A 'repository' is your project's storage space on GitHub.

PART 2 - CREATE A GITHUB REPOSITORY WHEN YOU ARE READY

1. Sign in at https://github.com in your browser.
2. Use the + menu near the top-right and choose New repository.
3. Enter a name, for example: delta-nyc-dashboard
4. Choose Public if you want a public portfolio repository. Public means anyone
   can see and download the uploaded code and data. Choose Private if that is
   your preference; Streamlit must be granted access to the private repository.
5. Leave the initialization options OFF: do not add a README, .gitignore,
   or license here. The prepared folder already supplies the first two.
6. Click Create repository.

PART 3 - UPLOAD THE CONTENTS OF THE PREPARED FOLDER

1. On the empty repository page, click the 'uploading an existing file' link.
   If the repository already has files, use Add file > Upload files instead.
2. Go back to File Explorer and OPEN GITHUB_UPLOAD_READY.
3. Press Ctrl+A to select the NINE items INSIDE it.
4. Drag those selected items together onto GitHub's upload area.
   Drag the three folders along with the six files; keep their contents inside.

PART 4 - DEPLOY TO STREAMLIT COMMUNITY CLOUD LATER

1. Go to https://share.streamlit.io and sign in/connect your GitHub account.
2. Choose Create app (or New app), then the option to deploy from GitHub.
3. Select the repository you just created.
4. Set Branch to main, or the exact branch name you confirmed on GitHub.
5. Set Main file path to: app.py
6. Open Advanced settings and select Python version 3.13.
7. Leave Secrets empty; this app needs none. Save the settings.
8. Choose an available app URL if desired, or accept the assigned one.
9. Click Deploy when you are ready to publish the website.
10. Wait for installation and startup. Streamlit reads requirements.txt and
    runs the app automatically. You do not run the pipeline or a terminal command.

PART 5 - CHECK THE HOSTED WEBSITE

1. Open the public app URL that Streamlit gives you.
2. Confirm the default view is Delta / NYC core / May 2026.
3. Confirm the four default metrics are:
   21.81% | 21.12% | 84.3% | 5,694

5. Try an airline filter, an airport filter, and a route search.
6. If the app fails, read/copy the error from Streamlit's logs. Check the file
